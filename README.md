# Microsoft AI Day @ JPMC

Live page for Microsoft AI Day at the JPMorgan Chase Plano office.
On a laptop or monitor it shows the flyer scaled to fit the window; on a phone it stacks into one column.
Every booking tag, the QR code, the Maps banner and the LinkedIn link are clickable.

## Publish on GitHub Pages
1. Create a repository (for example `ai-day-jpmc`).
2. Upload `index.html`, `.nojekyll` and the whole `assets` folder to the repository root.
3. Settings -> Pages -> Source: "Deploy from a branch", Branch: `main`, Folder: `/ (root)` -> Save.
4. After a minute the page is live at `https://<your-username>.github.io/ai-day-jpmc/`.

## Updating the agenda
Open `index.html` on GitHub, click the pencil icon, edit and commit. Things you will change most:
- `[NEXT VISIT DATE]`, `[ROOM]`, `[CHANNEL NAME]`
- Session times and descriptions in "The day at a glance"
